#### UC-05: {自分の投稿の編集}

- **アクター**: {ログイン済み利用者}
- **事前条件**: {ログインしていること、開いている投稿の作成者であること}
- **基本フロー**:
  1. {ログイン済み利用者}が{一覧表示画面で「編集」をおす}
  2. システムが投稿の作成者かどうかを判断し、いまのタイトル・本文・カテゴリをいれた編集ページを表示する
  3. ログイン済み利用者が編集フォームに入力し、「更新」を押す
  4. システムが投稿を更新し、一覧表示画面へリダイレクトする
- **代替フロー**:
  - {1}a. {投稿の作成者でない}：{編集ボタンは表示されず、urlを直接打ち込むと403エラーが表示される}
  - {3}a. {バリデーションエラー(タイトルまたは本文が空の場合)}：{エラーメッセージが表示され、投稿の更新はされない}
- **事後条件**: {一覧表示画面にて、更新した投稿が表示される}
- **受け入れ条件**:
  - [ ] 自分の投稿が表示されると、編集ボタンが表示される
  - [ ] 投稿を更新すると、更新した投稿が一覧画面に表示される
  - [ ] タイトルを空にして「更新」を押すと、エラーメッセージが表示され、投稿の内容は変わらない
